# Zomato Restaurant Data Analysis

A small exploratory data analysis project using Python to examine restaurant listings from Zomato. The notebook cleans restaurant ratings and explores restaurant categories, customer votes, online-order availability, ratings, and approximate cost for two through visualizations.

## Files

- `zom_analysis.ipynb` — analysis and visualizations
- `Zomato-data-.csv` — restaurant dataset
- `order_heatmap.png`, `votes_for_restaurants.png` — generated charts

## Run

Open the notebook in Jupyter and install `pandas`, `numpy`, `matplotlib`, and `seaborn`. Update the CSV file path in the notebook to match your local copy before running it.
